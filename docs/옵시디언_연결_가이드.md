# 옵시디언 연결 가이드

이 저장소 전체가 옵시디언 보관함입니다. Claude가 노트를 커밋하고 푸시하면, 옵시디언에서 Git으로 받아 봅니다.

## PC (Windows / Mac)
1. Git을 설치합니다. (https://git-scm.com)
2. 저장소를 받습니다.
   ```
   git clone https://github.com/dkttk970604-web/comes.git
   cd comes
   git checkout claude/focused-curie-lw8upu
   ```
3. 옵시디언에서 **보관함 열기 → 폴더를 보관함으로 열기**를 누르고 `comes` 폴더를 고릅니다.
4. **설정 → 커뮤니티 플러그인**에서 제한 모드를 끄고 다음 두 개를 설치하고 켭니다.
   - **Git** (Vinzent03): 자동 동기화. 설정에서 "Auto pull interval"을 10분 정도로 설정합니다.
   - **Dataview**: 주제 노트의 영상 목록 표를 자동으로 만듭니다.
5. 명령 팔레트(Ctrl/Cmd + P)에서 `Git: Pull`을 실행하면 최신 노트를 받습니다.

## 모바일 (iOS / Android)
Git 플러그인은 모바일에서도 동작합니다. GitHub 개인 액세스 토큰(Contents 읽기 권한)을 플러그인 설정에 넣고 저장소를 복제하면 됩니다.
