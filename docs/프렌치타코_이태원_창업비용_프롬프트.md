# 프렌치타코(BON Appetit) 이태원 창업비용 산출 프롬프트

인도네시아 프렌치타코 브랜드 BON Appetit의 한국 1호점(서울 용산구 이태원동 34-83, 지하 1층~2층 연면적 32.61평 + 루프탑 10평, 1층은 서브웨이식 오픈 키친, 지하 1층·2층·루프탑은 셀프 서빙 객석, 기존 카레집 자리, 배달·포장 비중 높음, 주류 판매) 창업비용을 표로 정리하고, 본사 대표에게 보낼 영문 양식까지 받기 위한 프롬프트입니다.

프롬프트는 두 개입니다.

| 프롬프트 | 하는 일 | 결과물 |
|---|---|---|
| 1. 창업비용 산출 | 시세를 검색해 비용을 계산 | 내부 검토용 상세표, 층별 배치, 월 손익, 확인 사항 (한국어) |
| 2. 대표 송부용 양식 | 프롬프트 1의 숫자로 문서 작성 | 영문 이메일과 첨부 양식, 검토용 한국어 번역 |

## 사용법

1. 웹 검색이 켜진 AI(Claude, ChatGPT 등)에서 **프롬프트 1**을 실행합니다. 건물 사진이 있으면 함께 첨부하고, `<추가 정보>`에서 아는 칸만 채웁니다.
2. AI가 확인 질문을 하면 답하거나 "가정으로 진행"이라고 입력합니다.
3. 결과를 검토합니다. `[추정]`, `[본사확인필요]` 표시가 붙은 큰 금액부터 실제 견적(시공업체 2~3곳, 구청·소방서 확인, 본사 회신)으로 바꿉니다.
4. **같은 대화창에서** 프롬프트 2를 입력합니다. 새 대화창에서 실행할 때는 프롬프트 1 결과의 "9. 영문 양식용 요약"을 프롬프트 2의 `<입력 자료>`에 붙여넣습니다.

프롬프트 2는 시세를 다시 찾지 않고 프롬프트 1의 숫자만 씁니다. 그래서 내부 상세표와 대표에게 보내는 금액이 서로 맞습니다.

## 프롬프트 1: 창업비용 산출

```
<역할>

</역할>

<목표>
인도네시아 프렌치타코 브랜드 'BON Appetit'의 한국 1호점을 서울 이태원에 여는 데 드는 창업비용을 산출합니다. 결과물은 내부 검토용이며 한국어로 씁니다.
1. 창업비용 상세표와 요약
2. 건물·입지 사전 점검, 층별 배치 검토, 월 손익
3. 가정·출처·확인 필요 사항 목록
4. 다음 단계(BON Appetit 대표에게 보낼 영문 양식 작성)에 넘길 요약
영문 양식 자체는 이 단계에서 만들지 않습니다.
</목표>

<확정 정보>

- 브랜드: 인도네시아 BON Appetit, 한국 첫 매장
- 주소: 서울특별시 용산구 이태원동 34-83
- 면적: 연면적 32.61평(약 107.8㎡) = 지하 1층 + 1층 + 2층. 층별 면적은 건축물대장으로 확인하고, 확인 전에는 1층·2층 각 약 11평, 지하 1층 약 10.6평으로 가정. 옥상 약 10평(약 33㎡)은 루프탑 좌석으로 사용 (옥상은 연면적에 포함하지 않음)
- 층별 용도:
  - 지하 1층: 객석
  - 1층: 주방 전용, 객석 없음. 서브웨이처럼 손님이 카운터에서 재료를 골라 주문하고, 자기 타코가 눈앞에서 만들어지는 것을 보는 오픈 키친. 결제, 음식 수령, 포장, 배달 라이더 픽업도 1층에서 처리

  - 루프탑: 객석
- 좌석: 테이블 15개 (지하 1층 5개, 2층 5개, 루프탑 5개로 가정). 2인석·4인석 비율을 가정해 총 좌석 수를 밝히고, 층별로 더 들어갈 수 있으면 최대 배치 수도 제시
- 서빙 방식: 셀프 서빙. 손님이 1층에서 받은 음식을 직접 들고 지하 1층·2층·루프탑으로 이동하고, 다 먹은 뒤 층별 퇴식대에 반납
- 계단: 1층↔2층은 건물 안 계단, 2층↔옥상은 2층 발코니 옆 외부 철제 계단, 1층↔지하 1층은 <추가 정보> 참고
- 엘리베이터: 없음
- 매출 구성: 배달·포장 매출 비중이 클 것으로 예상 (BON Appetit 본점도 배달 매출 비중이 큼). 본점의 실제 채널별 비중은 [본사확인필요]이며, 받기 전까지는 배달·포장 비중 30% / 50% / 70% 세 경우로 계산 (기준 50%)
- 주류: 판매함 (일반음식점으로 영업신고)
- 외관: 거의 손대지 않고 외벽 페인트 도장만 함
- 임대 조건: 보증금 1억 원, 월세 500만 원(부가세 별도로 가정), 권리금 없음
- 옥상 상태: 확인하지 못함 (방수·난간·바닥 상태 모름)
- 점포: 기존 카레 전문점 자리. 주방·홀 집기는 프렌치타코 브랜드 기준에 맞춰 전부 새로 구매 (카레집 집기는 사용하지 않음). 후드·덕트, 배관, 전기 같은 건물 시설은 재사용 여부를 검토
- BON Appetit와의 계약 조건(가맹비, 로열티, 광고분담금, 교육비, 트레이너 파견비 등)은 아직 협상 전이므로 이번 산출에서 제외
- 작성 기준일: 2026년 10월

    - 지하 1층·2층: 테이블 5개씩과 퇴식대가 들어가는지 확인합니다.
```
