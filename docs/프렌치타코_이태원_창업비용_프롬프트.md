# 프렌치타코(BON Appetit) 이태원 창업비용 산출 프롬프트

인도네시아 프렌치타코 브랜드 BON Appetit의 한국 1호점(이태원, 연면적 30평, 기존 카레집 자리) 창업비용을 표로 정리하고, 본사 대표에게 보낼 영문 양식까지 받기 위한 프롬프트입니다.

## 사용법

1. 웹 검색이 켜진 AI(Claude, ChatGPT 등)에서 사용합니다. 검색이 꺼져 있으면 출처 없는 숫자가 나옵니다.
2. `<추가 정보>`에서 아는 칸만 채웁니다. 특히 **층, 보증금·월세, 권리금과 포함 내역, 계약 형태**를 채우면 총액 오차가 크게 줄어듭니다.
3. AI가 확인 질문을 하면 답하거나 "가정으로 진행"이라고 입력합니다.
4. 결과에서 `[추정]`, `[본사확인필요]` 표시가 붙은 큰 금액부터 실제 견적(시공업체 2~3곳, 중개사, 본사 회신)으로 바꿉니다.
